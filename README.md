## 💻 Run Locally

You can run this portfolio on your local machine by following these steps:

**1. Clone the repository**

```bash
git clone https://github.com/ZahoorAhmed008/zahoor_ahmed_portfolio.git
```

**2. Navigate to the project directory**

```bash
cd zahoor_ahmed_portfolio
```

**3. Open the website**

Simply open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code.

---

## 🌐 Deployment

This portfolio is hosted on **Netlify** and connected directly to GitHub.

Every time new changes are pushed to the `main` branch, Netlify automatically deploys the updated website.

**Live Website:** [https://zahoor-ahmed.netlify.app](https://zahoor-ahmed.netlify.app)

## 📩 Contact Form Setup

The contact form uses [FormSubmit](https://formsubmit.co/) to deliver messages directly to my email.

**Setup instructions:**
1. Configure your email address in the contact form inside `index.html`.
2. Deploy the website.
3. Submit a test message through the contact form.
4. Open the confirmation email from FormSubmit and activate the form.
